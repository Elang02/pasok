When the loop runs

Read from the run log the loop writes after every pass. No value on this page is typed by hand.

This run, from the artefacts

Read from the files the chain wrote, not from the log below. A log row is written when the scheduled loop runs, so the newest row can be older than the state on disk.

Every run in the log

One row per run, newest first. A day with no row is a day the loop did not run. A row that says Stopped with a problem is kept rather than erased: it is the day the loop failed.

Every order, manual then by the agent

One unbroken record. Up to 12 October 2026 the buying was the distributor's own, and from 15 October the agent places it. Each row says who placed the order, the day the supplier promised, the day it actually landed, and what the agent was thinking when it sized the order.

The agent half is a replay: the same code that runs today was run day by day from 1 January, so every one of its orders comes from one version of the loop, not a mix of yesterday's rules and today's. It covers 15 to 22 October. The pass that ran this morning is the block at the top of this page; the ledger below is the replay.
