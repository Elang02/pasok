An order can be placed the right way and still end in an empty shelf, because a supplier can confirm it and then deliver the goods late or short. This page shows what actually arrived, supplier by supplier, against what each one promised.

What arrived

Read from the delivery records up to the snapshot. A delivery counts as short when fewer units arrived than the order asked for. It counts as late when it took longer than the supplier promised.

How each supplier delivers

One row per supplier, the one that runs latest first. A marked row delivers later than it promised.

Deliveries that ran late

One row per delivery that took longer than the supplier promised, the worst delay first. The order date is the day the order was placed.

What is still on the way

Each date below is a day a supplier has promised a delivery for an order that is still open. This stock has not arrived yet.
